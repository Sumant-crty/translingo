LIVE TRANSLATION CHAT

Two people, two languages, one conversation

Each side types in their own language. Every message is translated on the way to the other person, powered by Ollama Cloud (gemma4:31b-cloud) through this app's own server.

Sumant

Translation requests go to this app's own /api/translate route, which forwards them to Ollama Cloud using a server-side API key. The key never reaches the browser, so it's safe to deploy this publicly.
